# Print parts
You can find all the stl's required to print your own parts here. Note that there are seperate shell files for resin and filament printers. This is as the hinge parts must be printed seperatly using filament, to maintain acceptable strength and dimensional accuracy. 
The internal parts may be printed in resin or fdm. I personally prefer fdm for the holders, and resin for the buttons.

When printing make sure you scale appropriately for the material used, I had good results using 100.3% scale for pla. Also scale all buttons at 98% before printing.
